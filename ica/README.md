# ICA app

The project README, with what ICA does, how to run it, what is real and what is mocked, and the
data and privacy rules, is at the repo root: [../README.md](../README.md).

Quick start, from this folder (after copying `../.env.example` to `../.env` and adding your key):

```bash
npm ci
npm run dev -- -H 127.0.0.1   # http://127.0.0.1:3000, on this laptop only
```
